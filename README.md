# 潮汐合唱

《克苏鲁的呼唤》7 版。盐喉村每年交出一个名字，换一年渔获。这次被念到名字的，是你受雇寻找的那个人。

- **人数**：3 人（2–5 可调）
- **时长**：约 120 分钟
- **结构**：3 章 / 15 节点 / 4 个结局
- **内容**：世界书 18 条（6 条公开 / 12 条守秘人专属），地图地点 11 个

## 结构

| 部分 | 内容 |
|---|---|
| 第一章：退潮的衣物 | 滩涂三套衣服、奥古斯特的房间、进村问话 |
| 第二章：地窖与合唱 | 村小学名单、海丝特的厨房、冰厂账、夜里的合唱 |
| 第三章：交换 | 铜管与空位，四个结局 |

## 守秘人要点

1. **村子要「正常」。** 不要一进门就阴森。晒网、煮汤、孩子上学、冰厂装车——越正常，玩家越不安。恐怖来自「所有人都知道，只有你们不知道」。

2. **合唱分三次给。** 第一次只有一句「礼堂方向有孩子在唱歌，唱的不是英语」；第二次给歌词（音节）；第三次让玩家跟着哼。

3. **四个结局都不是胜利。** 砸铜管换来一年饥荒，带走孩子换来一夜寻找，接过空位换来被当成自己人，全村撤离换来「名字还在」。不要暗示哪个更对。

## 这个模组在讲什么

这个模组的核心不是怪物，是**共谋**。三十二户人家，没有一个人是被迫的。
